# Playbook Export Example

This directory holds example output shape for T61 Playbook-compatible exports.
Generated artifacts are convenience handoffs only; canonical authority remains
the reviewed workflow evidence, implementation contract, ADRs, and approved
blueprint.

Required sections:

- Runtime Tier
- Tool Permission Boundaries
- Human Approval Points
- Implementation Contract Deltas
- Eval Artifact Skeletons
- Task Blocks with Context-Refs
