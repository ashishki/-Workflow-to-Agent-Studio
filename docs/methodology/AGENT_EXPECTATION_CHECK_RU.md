# Проверка мифов об агентах

Purpose: не продавать заказчику миф "агент всё сделает сам", а показать
реальный уровень автономии для конкретного workflow.

## Почему это важно

Многие компании приходят к AI-автоматизации с ожиданием, что агент заменит
оператора, менеджера или инженера. На практике первый рабочий результат обычно
появляется быстро, но production-качество требует процесса: тестов, логов,
shadow mode, rollback, владельца процесса и ревью спорных кейсов.

Поэтому roadmap-отчет теперь обязан явно отвечать:

- что агент может делать в этом workflow;
- что агент не должен делать;
- какой человек остается ответственным;
- какие мифы опасны именно здесь;
- какие proof gates нужны до запуска.

## Что считается источником истины

Секция строится не из маркетингового обещания, а из уже рассчитанных частей
roadmap:

| Источник в отчете | Как используется |
|---|---|
| `do_not_automate_rationale` | превращается в список human-owned responsibilities |
| `human_gate` | определяет, кто утверждает запуск и какие действия требуют approval |
| `risks` | поднимает уровень осторожности для refund, legal, incident, diagnosis и похожих зон |
| `regression_tests` | становится proof gate перед rollout |
| `stop_conditions` | фиксирует условия остановки пилота |
| privacy/risk scores | понижает допустимую автономность для чувствительных workflow |

## Уровни автономии

| Уровень | Что значит |
|---|---|
| `assistive` | AI помогает с черновиками, классификацией или суммаризацией |
| `human_in_the_loop` | AI готовит решение, человек утверждает каждое рискованное действие |
| `bounded_agent_with_human_gate` | агент может выполнять ограниченные tool actions после gates |
| `high_autonomy_not_recommended` | высокий уровень автономии явно не рекомендуется |

## Коммерческий смысл

Эта секция усиливает presale:

- снижает риск разочарования после демо;
- показывает зрелость подхода: мы продаем не "магического агента", а внедряемый
  roadmap;
- помогает заказчику понять, какой специалист нужен внутри;
- заранее отделяет быстрый pilot от опасной production-автоматизации;
- дает аргумент для дополнительных услуг: AI Roadmap Sprint, pilot runbook,
  evaluation pack, proof layer, change-control playbook.

## Правило продукта

Если workflow связан с юридическими решениями, медицинскими выводами,
инцидентами, выплатами, refund, HR или финансовыми approvals, отчет не должен
создавать впечатление автономного агента. Максимум для первого этапа:
draft-only, shadow mode, human approval, logs, regression tests.
