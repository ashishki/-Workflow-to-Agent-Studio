# HVAC Lead Intake Public Demo Pack

Status: public-source demo material; not customer proof.

Source fixture:
`tests/fixtures/public_sources/hvac_lead_intake.notes.md`

Source register:
`docs/experiments/public_sources/lead_intake/source_register.md`

This pack demonstrates a local-service lead-intake workflow using public HVAC
service pages, appointment forms, service-area pages, FAQs, and contact
instructions. It is suitable for portfolio demonstration and regression checks,
but it does not satisfy real-pilot evidence gates, T34, T40, or commercial proof
claims.

- `source_register.md`: pointer to the public source register and fixture.
