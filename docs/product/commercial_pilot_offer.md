# Commercial Pilot Offer

Status: offer draft. Assumption-backed until real pilot evidence is recorded in
`docs/pilot_measurement.md`.

## First Sellable Offer

One-workflow AI implementation roadmap.

Target buyer:

- AI automation consultant;
- small agency owner;
- SMB founder/operator;
- COO or operations lead.

## Buyer Promise

In one narrow workflow, identify what to automate, what not to automate yet,
which implementation pattern fits, which data is required, which privacy mode is
safe, what the likely cost/time/team range is, and what must be validated before
build.

## Deliverables

- workflow map;
- process inventory row(s);
- AI opportunity map;
- do-not-automate-yet section;
- recommendation cards;
- privacy mode recommendation;
- cost/time/team assumptions;
- 30/60/90 day rollout plan;
- evaluation plan;
- verification appendix;
- implementation handoff task outline.

## Package Options

| Offer | Price Range | Scope |
|-------|-------------|-------|
| Mini audit | 300-800 USD | One workflow, one roadmap, limited review |
| Full SMB roadmap | 1500-5000 USD | Multiple workflows, priority map, 30/60/90 rollout |
| Consultant package | 5000-15000 USD | Reusable workflow intake, templates, pattern pack, implementation handoff |

## Required Inputs

Ask for one narrow workflow packet:

- SOP;
- discovery call transcript;
- pasted notes;
- form description;
- integration excerpt;
- anonymized examples;
- rough weekly/monthly volumes;
- current systems and owners.

Do not request:

- credentials;
- production tokens;
- database exports;
- raw passport/ID/medical/financial records;
- payment card data;
- full private customer archive.

## Proof Metrics

Pilot success should be measured by:

- time to reviewable roadmap;
- required-section acceptance rate;
- reviewer edit count;
- unsupported claim count;
- critical missing question count;
- whether the buyer would use the output to scope implementation.

## Public Claim Boundary

Before pilot proof:

- "synthetic demo";
- "roadmap methodology";
- "local-first prototype";
- "assumption-backed offer".

After pilot proof:

- cite the pilot measurement row;
- state what was measured;
- avoid extrapolating one pilot into broad ROI claims.
